# Raw data

Place the following local files in this directory:

- `nhanes.csv` — the participant-level NHANES table used for the project.
- `variables_explained.csv` — the variable dictionary uploaded with the project.

Do **not** commit the full NHANES patient table to GitHub unless you have verified that your chosen distribution/repository terms allow redistribution.

The supplied `variables_explained.csv` is semicolon-delimited and Latin-1 encoded; the project loader handles that format automatically.

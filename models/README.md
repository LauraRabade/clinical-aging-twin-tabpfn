# Models

`age_model.json` and `mortality_model.json` are small `tabpfn-client` records pointing to fitted models stored server-side by Prior Labs.

Important: fitted model records are only loadable by the account that created the fit. For a reproducible public repository, **do not rely on these JSON files alone**. The notebooks in `notebooks/02_train_age.ipynb` and `notebooks/03_train_mortality.ipynb` reproduce the fits when a valid `TABPFN_TOKEN` is available.

For a public demo, the Streamlit app can fall back to the small demo training tables generated by notebook 01 and fit a fresh TabPFN-3.5 model using the viewer's own token.
